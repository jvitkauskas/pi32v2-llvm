# pi32v2-llvm

LLVM 23.1.4 with an experimental target for **pi32v2**, the CPU core of JieLi's AC79 chips (the AC791N in the
M-VAVE FM-1 and SMK-37 Pro): clang, `ld.lld` and the binary tools, able to build that firmware without JieLi's
closed toolchain. Unofficial; not affiliated with JieLi or M-VAVE.

This branch (`pi32v2`) is the release tag `llvmorg-23.1.4` with the target's commits on top. The target lives in
`llvm/lib/Target/PI32V2`, with small hooks elsewhere (the triple, ELF machine 241 and its relocations, clang's
target and `interrupt` attribute, the `ld.lld` port in `lld/ELF/Arch/PI32V2.cpp`) and tests in
`llvm/test/CodeGen/PI32V2`, `llvm/test/MC/PI32V2`, `llvm/test/MC/Disassembler/PI32V2` and
`clang/test/CodeGen/pi32v2-*.c`.

The instruction descriptions, assembler tables and disassembler tests (the files that say `Generated by
pi32v2-isa`) are generated from the instruction table in
[jvitkauskas/pi32v2-isa](https://github.com/jvitkauskas/pi32v2-isa); change the table there and regenerate.
That repository also has the documentation: the backend's status and how it is checked
([docs/LLVM.md](https://github.com/jvitkauskas/pi32v2-isa/blob/main/docs/LLVM.md)), building and using the
toolchain ([docs/TOOLCHAIN.md](https://github.com/jvitkauskas/pi32v2-isa/blob/main/docs/TOOLCHAIN.md)), the ISA,
the ABI and the hardware results.

## Building

```sh
cmake -G Ninja -S llvm -B build -DCMAKE_BUILD_TYPE=Release \
  -DLLVM_TARGETS_TO_BUILD="" -DLLVM_EXPERIMENTAL_TARGETS_TO_BUILD=PI32V2 \
  -DLLVM_ENABLE_PROJECTS="clang;lld" -DLLVM_DEFAULT_TARGET_TRIPLE=pi32v2
ninja -C build clang lld llc
build/bin/llvm-lit llvm/test/CodeGen/PI32V2 llvm/test/MC/PI32V2 llvm/test/MC/Disassembler/PI32V2
```

pi32v2-isa's `tools/llvm/package.sh` builds the release package (statically linked tools, compiler-rt's
builtins and the runtime), and `tools/llvm/ctest.py` checks the code generator against JieLi's compiler in a
simulator.
